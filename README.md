# 🗚️ Calculator

Máy tính với giao diện hiện đại, hỗ trợ đầy đủ các phép toán cơ bản và một số phép toán nâng cao.

## 🚀 Demo

**🔗 [Xem live tại đây](https://sinh1011.github.io/calculator/)**

## ✨ Tính năng

- Phép cộng, trừ, nhân, chia
- Phép tính phần trăm
- Xóa từng ký tự và xóa toàn bộ
- Hiển thị lịch sử tính toán
- Giao diện responsive, hỗ trợ cả máy tính và điện thoại
- Hỗ trợ bàn phím

## 🛠️ Công nghệ

- HTML5
- CSS3
- JavaScript (ES6+)
